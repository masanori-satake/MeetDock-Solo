## 2026/09/14 - TreeViewインラインコマンドの安全確認とコマンドパレット併用パターン
**学び:** VS Code TreeView のインラインアクション用コマンドは、コマンドパレット等から引数なしで実行された場合に無視されがちである。引数の有無をチェックし、未指定時は QuickPick で対象を選択可能にすること、および破壊的操作（削除など）には `{ modal: true }` を付与した警告ダイアログを挟むことで、誤操作防止とアクセシビリティ・利便性が向上する。
**アクション:** 今後追加・変更する破壊的操作コマンドには、この二段構え（QuickPick選択＋モーダル確認ダイアログ）のパターンを適用する。
